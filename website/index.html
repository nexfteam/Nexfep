About Nexfep

Nexfep is a desktop app framework built on @webviewjs/webview, written in TypeScript. It provides a window pool, IPC, system tray, logging and a CLI bundler so you can build cross-platform desktop apps with HTML/CSS/TS. The project is still in early development.

Quick Start

import { Application } from "nexfep";

const app = new Application();

const window = await app.windows.createWindow({
  visible: true,
  decoration: false,
});

await window.loadHTML("<h1 nexfep-area-drag>Hello Nexfep!</h1>");
